# rclone-pc

Página pública (GitHub Pages) del cliente OAuth propio con el que monto mi Google Drive como
carpeta en el PC mediante [rclone](https://rclone.org). Google pide una página de inicio y una
política de privacidad para el cliente:

- `index.html`: qué es la aplicación;
- `privacy.html`: política de privacidad.
